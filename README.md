# 贪吃蛇 · 多人版

一个带账号、实时观战和好友排行榜的贪吃蛇。跑在你自己电脑上，同一个 Wi-Fi 里的人都能访问。

**零依赖**：只用 Node 内置模块，不需要 `npm install`。

---

## 快速开始

1. 双击 **`start-server.cmd`**。
2. 窗口会打印出网址，例如：
   ```
   这台电脑上：      http://localhost:8000/
   手机 / 平板：     http://192.168.1.23:8000/
   ```
3. 手机连**同一个 Wi-Fi**，Safari 里输入第二个地址。
4. 第一次进去输个昵称 → 注册 → 开始玩。**以后打开这台设备不用再注册。**
5. 玩完关掉黑窗口即可停止（下次再双击）。

> iPhone / iPad 建议 Safari → 分享 → **添加到主屏幕**，之后就是全屏无地址栏。

**连不上**：先允许 Windows 防火墙（勾**专用网络**），再把 Wi-Fi 网络配置文件设为**专用**而不是「公用」。详细排查见文末。

## 功能

### 登录：注册一次就够

第一次输入昵称注册，服务器发一个**令牌**存在这台设备的浏览器里。以后打开自动进入你的账号，不用再输任何东西。

> ⚠️ 令牌就是账号的唯一凭证（按你的要求不设密码）。**清掉浏览器数据或换设备就找不回账号**，除非你提前备份了令牌。
> 在「我」那一页可以**复制令牌**；在注册页的「换设备登录」里粘贴令牌就能找回账号和全部战绩。

### 查看码：把你的游戏分享出去

注册后你会得到一个 **6 位查看码**（如 `K7M2QX`），在「我」那一页能复制/分享。

任何人拿到这串码，输入后就能：

- **实时看到你在玩**——你的蛇每一步都会推送到他的屏幕上，他看到的画面和你看到的几乎一样；
- 看到你的**历史战绩**：最高分、总局数、平均分、最近每一局的分数/长度/时长；
- 看到你**是否在线**。

### 好友：加过一次就不用再输码

在观战页点「**加为好友**」即可关注，**不需要对方同意**。之后：

- 「排行」页的**我关注的人**列表里直接点「看」就能观战，不用再输码；
- 对方能看到「**关注我的人**」列表；
- 双方互相关注时会标上「**互相关注**」。

### 排行榜

「排行」页把你和**你关注的人**按**最高分**排在一张表里（同分时比总局数），每行显示：最高分、总局数、平均分、最近一局时间、在线状态。

### 在线状态的判定

你在游戏页时，客户端每 2 秒（有人在看时是每 40 毫秒）向服务器上报一次。超过 **15 秒**没有上报就算离线。

## 文件结构

```
server.js           后端：账号 / 查看码 / 观战 SSE / 好友 / 排行 / 静态文件
selftest.js         接口自测脚本（node selftest.js）
start-server.cmd    双击启动（Windows）
public/
  index.html        界面骨架
  style.css         样式（移动优先）
  app.js            前端逻辑：登录、上报、观战、好友、排行
  game.js           游戏引擎 + 渲染（本地玩和观战共用同一套）
snake.html          离线单人版：双击就能玩，不需要服务器、不需要联网
data/
  db.json           所有账号 / 好友 / 战绩（服务器第一次保存时自动创建）
```

`snake.html` 是**独立**的：它不联网、没有账号和好友，只保留单人玩法。想一个人安静地玩、或者不想开服务器时用它。

## 自测（重要）

因为这套东西包含后端和实时推送，出问题时先跑自测，它能告诉你到底是哪一层坏了：

```bat
node selftest.js
```

它会：起一个临时服务器（用临时数据目录，**不会碰你的 data/**）→ 完整跑一遍注册、登录、上报、观战 SSE、战绩、关注、排行榜、重启后数据还在 → 逐条打印 `PASS` / `FAIL` → 最后给出 `X passed, Y failed`。

全部 PASS 说明后端是好的，剩下的问题一定在浏览器或网络层。

## 数据与隐私

- 所有数据存在这台电脑的 **`data/db.json`**，不上传任何地方。
- 想看谁、给谁看，完全由**查看码**控制：码只给信任的人。
- 传输是局域网 **明文 http**，不设密码（按你的选择）。同一个 Wi-Fi 下理论上有人可以抓包看到数据，**当成朋友间的小玩具用，别放敏感信息**。
- 备份：直接复制 `data/db.json` 即可。清空所有数据就把它删掉再重启服务器。

## 可调参数

### 游戏

在 `public/game.js` 开头：

| 参数 | 说明 |
| --- | --- |
| `SPEED_LEVELS` | 四档速度，每档 `base`（开局每步毫秒）、`min`（最快上限）、`ramp`（每吃一个加快多少，0 = 匀速） |
| `COLORS` | 配色 |

界面上「慢 / 中 / 快 / 极速」的文字是从 `SPEED_LEVELS` 自动生成的，改数值不用改界面。

### 服务器

在 `server.js` 开头：

| 参数 | 说明 |
| --- | --- |
| `DEFAULT_PORT` | 端口，默认 8000（也可以用环境变量 `PORT`） |
| `HISTORY_MAX` | 每人保留多少条战绩，默认 100 |
| `NAME_MAX` | 昵称最大字数，默认 12 |
| `ONLINE_MS` | 多久没上报算离线，默认 15000 |

端口被占用时：把 `start-server.cmd` 里的 `set "PORT=8000"` 改成 `8080`。

## 常见问题

**手机连不上，电脑上 localhost 能开**
防火墙没放行。第一次运行会弹「Node.js JavaScript Runtime」的提示，必须点**允许**并勾**专用网络**。漏了点过取消，用管理员 PowerShell 补一条：

```powershell
New-NetFirewallRule -DisplayName "Snake LAN 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
```

**还是连不上**
Wi-Fi 被 Windows 当成「公用网络」。设置 → 网络和 Internet → Wi-Fi → 点你的网络名 → 网络配置文件改成**专用**。

**公司 / 酒店 / 学校 Wi-Fi 连不上**
这类网络常开 AP 隔离，设备之间互相看不见。用手机开热点，电脑连热点，重新双击 `start-server.cmd`，用新打印的地址。

**观战页一直显示「还没有画面」**
对方还没开始那一局（他在「准备中」状态时只会显示初始棋盘）。让他点一下开始，画面就会动起来。

**观战画面卡住不动**
确认他的页面还在「玩」那一页。切到「我」或「排行」时会自动暂停并停止上报。

**忘了令牌 / 清了浏览器数据**
只要备份过令牌就能在注册页的「换设备登录」找回。没备份就只能重新注册（旧战绩还在服务器上，但你拿不回来了）。

**注册时提示昵称重复**
会自动加后缀（如 `小明#482`），两个人都能各自用，互不影响。

**`node selftest.js` 报 Node 版本太老**
需要 Node 18 及以上（用到了内置 `fetch`）。

## 兼容性

- 服务器：Node 18+（Windows / macOS / Linux 都行）。
- 浏览器：支持 `fetch` / `EventSource` / Canvas 的现代浏览器。iOS 13+（方向盘用 `pointerdown`，老浏览器走 `click` 兜底）。
- 手机 / 平板：竖屏上下排布，横屏时棋盘在左、控制在右；适配 iPhone 安全区；屏蔽下拉刷新、橡皮筋、双击缩放、长按菜单。
