========================================
  贪吃蛇 —— 解压后怎么玩
========================================

这个文件夹里有两个入口，你想怎么玩都行。


■ 入口一：一个人玩
  完全不需要任何网络、不需要服务器、不需要安装任何东西。

     直接双击  snake.html

  就这样，打开就是游戏。
  （速度可调，手机上也能玩，但这些都不需要联网。）


■ 入口二：和朋友互相看、比排行
  需要在同一个 Wi-Fi 下（局域网，不是外网）。

  1. 双击  start-server.cmd

     弹出的黑窗口里会打印两个网址，记住 "On your phone:" 后面那一行，
     形如：  http://192.168.1.23:8000/

  2. 手机连上和电脑【同一个 Wi-Fi】
     （手机上开着 4G/5G 没关系，只要连了同一个 Wi-Fi 就会走 Wi-Fi）

  3. 手机浏览器（iPhone 用 Safari）地址栏输入那个网址
     注意：只要输到端口 :8000 就够了，后面的路径不用打

  4. 第一次进去输个昵称注册，以后打开这台设备就不用再注册了

  玩的时候【千万别关那个黑窗口】，关了服务器就停了。

  这条路径不需要外网（这个 Wi-Fi 上不了网也没关系），
  但要求电脑和手机在同一个 Wi-Fi 里。

  start-server.cmd 需要电脑上有 Node.js 或 Python。
  如果两个都没有，它会打印错误提示，那你就用【入口一】。


■ 记住自己的账号
  多人版不设密码，靠一个「令牌」认人。
  进去之后去「我」那一页，点【复制令牌】保存好。
  换手机或清掉浏览器数据后，只有靠它才能找回账号和战绩。

  另外「我」那一页有一个 6 位【查看码】，发给朋友，
  他输进去就能实时看你在玩，还能看到你的历史战绩。


■ 换文件夹 / 换电脑时别丢了账号
  所有账号、好友关系、历史战绩都存在同级的  data  文件夹里
  （就一个文件  data\db.json ）。

  这个 zip 里【故意没有包含】data 文件夹，免得把你的账号一起发给别人。
  所以如果你想在新解压出来的文件夹里继续用现在的账号，
  请把老的  data  文件夹整个复制到新文件夹里（和 server.js 放在一起）。
  不放的话就是全新开始，以前的账号还在老文件夹里，只是新文件夹看不见。


■ 想检查多人版后端有没有问题（可选）
  在这个文件夹里，地址栏输入 cmd 回车，然后运行：

      node selftest.js

  它会逐条打印 PASS / FAIL，最后给出 "X passed, Y failed"。
  全 PASS 说明后端是好的。


■ 连不上时先查这两件事（99% 是这两个）
  1. Windows 防火墙：第一次运行 start-server.cmd 会弹提示，
     必须点【允许访问】并勾上【专用网络】。
  2. 这个 Wi-Fi 被 Windows 当成「公用网络」了：
     设置 → 网络和 Internet → Wi-Fi → 点你的网络名 → 改成【专用】。
